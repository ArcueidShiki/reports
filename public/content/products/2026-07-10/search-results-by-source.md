## 10. Product deep-dive notes & reviews
### Frugon (frugon.rodiun.io | github.com/Rodiun/frugon)
- Tagline: "Your LLM bill is leaking." Free, local, MIT open source LLM cost analyzer.
- Flow: `frugon capture` (local proxy) → run app → `frugon analyze` → cost breakdown + per-call routing recommendation ("which calls a cheaper model handles just as well, and which to leave alone"). Token counting/pricing math all on-machine, zero external calls.

### Foreman (github.com/Northwood-Systems/foreman)
- Self-hosted LLM gateway; single Go binary between coding agent and providers. Keys/traffic stay in-network; tracks every dollar; switch providers with no code changes.
- Policy-based routing: frontier models where quality matters, cheap models for routine work; pins conversations to a model while provider prompt-cache is warm ("routing never burns your cache to save pennies").

### Kastor (getkastor.dev | github.com/weirdGuy/kastor)
- "Terraform for AI agents": typed HCL specs for agents/tools/prompts/models → generates LangGraph project; plan/apply/state reconciliation for hosted agents (in design). v0, early.
- Idea: "agents need a versionable, reviewable, declarative contract before they become serious software."

### Aura (producthunt.com/products/aura-28)
- Semantic version control for AI coding agents on top of Git; hashes AST not lines; intent ("the Why") recorded in plain English; blocks undocumented AI commits; Amnesia Protocol rewinds broken functions; claims 95% LLM token savings; 100% local; Apache 2.0.

### Wispr Flow (wisprflow.ai)
- $15/mo; Mac/Windows/iOS dictation with auto-edits, command mode, 100+ languages; "writes in your style".
- Traction: 270 F500 companies (Nvidia, Amazon); 10x ARR in 5 months (per founder); raising ~$260M @ ~$2B.
- Negative reviews: Trustpilot 2.7/5 vs G2 4.5/5 gap; Reddit reports "works 60% of the time" post-payment; Windows app ~800MB RAM / 8% idle CPU, freezes VS Code/Notepad++; captures periodic screenshots of active window sent to cloud (CTO admitted + apologized after banning the whistleblower — viral Reddit thread); cloud-only, no offline; r/macapps: best for beginners, Superwhisper for privacy, Spokenly free.

### Willow Atlas 1 (willow.ai)
- "Frontier speech-to-text model", claims outperforms ElevenLabs/Deepgram/OpenAI "by a wide margin"; 1.2% WER claim; built on human-in-the-loop transcription infra for real-time dictation.
- Context: top STT providers (Deepgram Nova-3, AssemblyAI Universal-3 Pro, OpenAI gpt-4o-transcribe, ElevenLabs Scribe v2, Microsoft MAI-Transcribe-1) within 1–2pp of each other on LibriSpeech/FLEURS — Willow's claim is aggressive.
